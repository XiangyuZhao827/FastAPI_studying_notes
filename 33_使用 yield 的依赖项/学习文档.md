## 5. yield 依赖：资源生命周期

```python
def get_db():
    db = DBSession()  # 本段为概念代码，DBSession 需由具体数据库库提供
    try:
        yield db
    finally:
        db.close()
```

依赖 `yield` 可在路由处理前提供资源，之后执行清理。子依赖应按与创建相反的顺序退出。`Depends(..., scope="function")` 的退出发生在发送响应之前；默认 `scope="request"` 在响应结束后退出。流式响应若仍需使用资源，应谨慎选择作用域。

## 6. Agent 综合应用

在 `/agents/{agent_id}/chat` 中：Body 模型校验聊天请求，Header 读取认证信息，子依赖获取用户和 Agent，业务授权检查用户是否有权访问该 Agent，yield 依赖提供并清理数据库 Session，路由函数只负责调用 Agent 并组成响应。

**核心记忆：**Depends 管理可复用的请求处理与资源准备，不会自动赋予登录与授权能力。
