## Q044｜中｜授课复习

**题目：** React 聊天页面构建后得到 `dist/index.html` 和静态资源。官方 `app.frontend("/", directory="dist")` 主要做什么？

- **A.** 提供已经构建好的前端文件，供浏览器访问
- **B.** 把网页变成 SQL 数据库
- **C.** 替开发者编写整套 React 源码
- **D.** 运行 LangGraph 并返回工具结果

**正确答案：A. 提供已经构建好的前端文件，供浏览器访问**

**解析：** `app.frontend()` 面向已构建的前端应用，它提供目录中的文件，不会自动设计聊天界面或运行 Agent 推理。

## Q080｜难｜授课复习

**题目：** 前端 SPA 里存在 `/dashboard/settings` 页面路由，但服务器没有同名文件。为什么可以考虑 `fallback="index.html"`？

- **A.** 这会把所有不存在的 API POST 都变成 200
- **B.** 它会禁用登录鉴权
- **C.** 符合条件的 HTML 导航请求可返回前端入口，再由客户端路由决定显示哪个页面
- **D.** 它会自动生成 dashboard 的数据库表

**正确答案：C. 符合条件的 HTML 导航请求可返回前端入口，再由客户端路由决定显示哪个页面**

**解析：** 客户端路由可能由浏览器端 JavaScript 解释。合适的 HTML 导航请求可回退到 index.html；缺失的 JS/CSS 等资源不应被无条件当作首页返回。
