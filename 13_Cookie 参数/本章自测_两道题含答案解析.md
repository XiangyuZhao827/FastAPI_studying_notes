## Q001｜易｜授课复习

**题目：** 浏览器已经保存了符合发送条件的会话 Cookie，随后发请求时 Cookie 通常位于哪里？

- **A.** 请求头中的 Cookie 字段
- **B.** JSON 中的 message
- **C.** 路径参数
- **D.** 响应状态码

**正确答案：A. 请求头中的 Cookie 字段**

**解析：** Cookie 通常由浏览器根据域名、路径、SameSite 等规则自动附加到请求头。后端的 `Cookie()` 从这里提取对应值。

## Q094｜难｜授课复习

**题目：** 接口同时声明名为 `theme` 的 Query 参数和使用 `Cookie(alias="theme")` 的 Cookie 参数，用户只访问 `?theme=dark`。Cookie 对应参数应是什么？

- **A.** 必然返回 500
- **B.** 一定是 dark
- **C.** 自动从 Query 复制
- **D.** 仍是缺失或其默认值

**正确答案：D. 仍是缺失或其默认值**

**解析：** Query 和 Cookie 虽然可同名，却来自 HTTP 的不同位置。URL 中的 `?theme=dark` 不会自动变成 Cookie，必须由客户端实际发送 Cookie 字段。
