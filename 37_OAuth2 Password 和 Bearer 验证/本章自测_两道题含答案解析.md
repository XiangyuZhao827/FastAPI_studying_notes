## Q054｜中｜授课复习

**题目：** OAuth2 Password 教学流程里，`POST /token` 登录成功常返回哪种结构？

- **A.** `{"status_code":401}`
- **B.** `{"user_agent":"chrome"}`
- **C.** `{"file_size":100}`
- **D.** `{"access_token":"...","token_type":"bearer"}`

**正确答案：D. `{"access_token":"...","token_type":"bearer"}`**

**解析：** 令牌接口通常返回访问令牌和 token_type。之后客户端才会通过 `Authorization: Bearer ...` 使用它访问受保护资源。

## Q059｜中｜授课复习

**题目：** 在教学版 `POST /token` 中，`OAuth2PasswordRequestForm` 从哪里获得用户名与密码？

- **A.** 服务器的 OpenAPI 标签
- **B.** Form Body 的 username、password 字段
- **C.** GET 请求的响应头
- **D.** JSON 顶层键

**正确答案：B. Form Body 的 username、password 字段**

**解析：** OAuth2 Password 教学流程用标准表单字段，FastAPI 通过类依赖将它们暴露为 `form_data.username` 和 `form_data.password`。
