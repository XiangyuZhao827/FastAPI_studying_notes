## Q036｜中｜授课复习

**题目：** 为 Agent API 设置 `title`、`description`、`version`，主要改善什么？

- **A.** 强制所有接口都只能用 GET
- **B.** API 元数据与 `/docs` 的可读性
- **C.** 自动创建所有数据库表
- **D.** 自动训练 Agent

**正确答案：B. API 元数据与 `/docs` 的可读性**

**解析：** 这些配置项用于 OpenAPI 项目介绍和文档显示；`version` 是应用 API 版本，不是 FastAPI、Python 或底层模型的版本。

## Q079｜难｜授课复习

**题目：** 你通过 `openapi_tags` 给 Chat 分类写了说明，再为路由写 `tags=["Chat"]`。对这两处的关系，哪种解释正确？

- **A.** tags 是权限检查，不允许普通用户访问
- **B.** openapi_tags 会自动生成 POST /chat 业务路由
- **C.** 只要设置 openapi_tags 就禁用了 OpenAPI
- **D.** openapi_tags 定义标签说明，路径操作的 tags 决定归属，二者都不自动实现认证

**正确答案：D. openapi_tags 定义标签说明，路径操作的 tags 决定归属，二者都不自动实现认证**

**解析：** 标签元数据用于文档分类与介绍，需要和路由标签名称对应；文档组织与用户认证是独立问题。
