## Q016｜易｜授课复习

**题目：** 把普通 Python 类 `CommonQueryParams` 传给 `Depends(CommonQueryParams)`，通常会得到什么？

- **A.** 一个 HTML 表单
- **B.** 固定 HTTP 404
- **C.** 根据构造参数创建的实例
- **D.** 类的源码字符串

**正确答案：C. 根据构造参数创建的实例**

**解析：** 类本身是可调用对象。FastAPI 能分析构造函数参数并创建实例，路由可使用 `commons.q` 等属性。

## Q035｜中｜授课复习

**题目：** `commons: Annotated[CommonQueryParams, Depends()]` 为什么在官方类依赖示例里可行？

- **A.** `Depends()` 会随机选择类
- **B.** 所有类都无需构造
- **C.** 这是固定的 HTTP 头
- **D.** FastAPI 可从类型注解推断这个类依赖

**正确答案：D. FastAPI 可从类型注解推断这个类依赖**

**解析：** 当注解里明确写出类时，FastAPI 可以从类型推断依赖对象，并按类的可调用签名构造实例。这是完整写法 `Depends(CommonQueryParams)` 的简写。
