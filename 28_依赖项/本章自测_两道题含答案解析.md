## Q030｜易｜授课复习

**题目：** `Depends(get_current_user)` 最核心的含义是什么？

- **A.** 把参数变成 URL 查询字符串
- **B.** 由 FastAPI 调用依赖并提供其结果
- **C.** 客户端必须上传一个 Python 文件
- **D.** 将函数立即运行一次后永久缓存

**正确答案：B. 由 FastAPI 调用依赖并提供其结果**

**解析：** `Depends()` 声明依赖关系，FastAPI 会在处理请求时求解依赖，把结果提供给所需位置；一般传入函数对象而不是调用结果。

## Q098｜难｜授课复习

**题目：** 一个 Agent 请求已登录但 `agent_id` 对应资源不存在，同时 `max_steps` 也不符合请求模型规则。对设计正确的系统而言，最重要的原则是？

- **A.** 所有情况都固定返回 200
- **B.** 在进入业务执行前验证输入，并让业务层单独处理资源存在性与授权
- **C.** 让 Agent 先运行再随意选择错误码
- **D.** 只要用户登录就忽略参数错误

**正确答案：B. 在进入业务执行前验证输入，并让业务层单独处理资源存在性与授权**

**解析：** 请求输入校验和业务检查是不同层次：FastAPI/Pydantic 验证格式与数值，依赖完成认证，业务检查资源与权限。多个错误并存时具体先返回哪个取决于处理流程。
