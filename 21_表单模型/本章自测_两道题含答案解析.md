## Q042｜中｜授课复习

**题目：** 登录表单模型写成 `data: Annotated[LoginForm, Form()]` 时，客户端应该提交哪一种数据？

- **A.** `application/json` 中的完整 JSON
- **B.** 通过响应头传密码
- **C.** 只在 URL 中加入用户名
- **D.** 表单编码的字段，例如 username 和 password

**正确答案：D. 表单编码的字段，例如 username 和 password**

**解析：** `Form()` 告诉 FastAPI 从表单请求体读取并创建模型。虽然使用 Pydantic 模型，客户端发送格式仍是表单而不是 JSON。

## Q088｜难｜授课复习

**题目：** 登录请求发送 JSON `{"username":"alice","password":"123"}`，服务端使用 `OAuth2PasswordRequestForm`。哪种排查思路最合适？

- **A.** 把 password 改成路径参数
- **B.** 检查是否把 JSON 错发给本应接收表单的接口
- **C.** 删除 `@app.post("/token")`
- **D.** 修改 response_model 即可

**正确答案：B. 检查是否把 JSON 错发给本应接收表单的接口**

**解析：** `OAuth2PasswordRequestForm` 依赖表单字段，JSON Body 不符合其预期。应先检查 Content-Type 与字段位置，而不是改动响应模型。
