## Q015｜易｜授课复习

**题目：** 服务器有 `static/logo.png`，通过 `app.mount("/static", StaticFiles(directory="static"), name="static")` 暴露后，浏览器通常应访问哪个 URL？

- **A.** `/chat?logo=1`
- **B.** `/logo.py`
- **C.** `/api/secret`
- **D.** `/static/logo.png`

**正确答案：D. `/static/logo.png`**

**解析：** mount 把 URL 前缀 `/static` 映射到服务器目录 `static`。这个机制适合提供 CSS、JS、图片等已有静态文件。

## Q052｜中｜授课复习

**题目：** 用户上传了包含私密信息的 PDF，能否直接放到公开的 StaticFiles 目录下方便下载？

- **A.** 最好不要；应通过受保护的文件管理和授权下载接口控制访问
- **B.** 必须先把它改成 CSS
- **C.** 可以，因为静态文件会自动检查 JWT
- **D.** 可以，因为文件扩展名是 PDF

**正确答案：A. 最好不要；应通过受保护的文件管理和授权下载接口控制访问**

**解析：** StaticFiles 本身用于公开或按挂载方式提供文件，不自动依据用户身份控制每份文件的访问权限；私人知识库文件应有独立访问控制。
