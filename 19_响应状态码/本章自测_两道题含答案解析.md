## Q013｜易｜官方补充

**题目：** 新建 Agent 成功后，`@app.post("/agents", status_code=201)` 中的 201 主要意味着什么？

- **A.** 用户已通过 OAuth2
- **B.** 默认成功响应为 201 Created
- **C.** 关闭自动文档
- **D.** 请求必须等 201 秒

**正确答案：B. 默认成功响应为 201 Created**

**解析：** 201 是 HTTP 创建成功状态码，`status_code` 位于路径操作装饰器中；它既影响实际成功响应也进入 OpenAPI 文档。

## Q050｜中｜官方补充

**题目：** 一个删除 Agent 的接口想在成功时只返回 `204 No Content`，最重要的响应规则是什么？

- **A.** 204 必须附带完整 JSON
- **B.** 204 不允许包含响应体
- **C.** 204 会自动阻止任何用户访问
- **D.** 204 表示未找到

**正确答案：B. 204 不允许包含响应体**

**解析：** 204 表示成功但没有响应内容，因此不能携带响应体。它与常见的 200（成功并可能有内容）、201（创建成功）语义不同。
