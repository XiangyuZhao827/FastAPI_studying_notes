## 1. Depends()：声明当前路由需要什么

```python
from typing import Annotated
from fastapi import Depends, FastAPI

app = FastAPI()

def common_parameters(q: str | None = None, skip: int = 0, limit: int = 100):
    return {"q": q, "skip": skip, "limit": limit}

@app.get("/agents")
def list_agents(commons: Annotated[dict, Depends(common_parameters)]):
    return commons
```

`Depends(common_parameters)` 传函数对象而不是 `common_parameters()` 的执行结果。FastAPI 负责读取依赖项自身声明的参数，执行后把结果提供给 `commons`。Depends 并不是一种新的 HTTP 参数来源。

**核心记忆：**Depends 管理可复用的请求处理与资源准备，不会自动赋予登录与授权能力。
