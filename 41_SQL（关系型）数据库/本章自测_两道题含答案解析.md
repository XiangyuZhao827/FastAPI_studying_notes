## Q046｜中｜官方补充

**题目：** FastAPI 官方 SQL 数据库章节使用 SQLModel 说明怎样保存数据。在该示例中，Session 最主要负责什么？

- **A.** 与数据库交互并跟踪数据操作，供路由查询或更新
- **B.** 将 React 页面构建为 dist
- **C.** 从 Header 读取 Bearer Token
- **D.** 定义 SSE 事件名称

**正确答案：A. 与数据库交互并跟踪数据操作，供路由查询或更新**

**解析：** SQLModel 的 Session 搭配 Engine 用于执行查询、添加记录、提交等操作。官方通过 yield 依赖为请求提供会话，并在结束时清理资源。

## Q100｜难｜官方补充

**题目：** Agent 数据库内部含 `secret_name` 或其他敏感字段，而对外 API 只能提供公开信息。更合理的设计是什么？

- **A.** 让前端自行隐藏敏感字段即可
- **B.** 把敏感字段改名后全部公开
- **C.** 始终直接返回表模型所有字段
- **D.** 分离数据库表模型、创建/更新模型和公开响应模型，输出时只暴露公共字段

**正确答案：D. 分离数据库表模型、创建/更新模型和公开响应模型，输出时只暴露公共字段**

**解析：** 官方 SQLModel 教程进一步使用 Hero、HeroCreate、HeroUpdate、HeroPublic 等不同模型，把存储、输入和公开输出职责分开，降低内部字段泄露风险。
