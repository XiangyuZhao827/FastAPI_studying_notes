# 📘 FastAPI 查询参数：零基础完整讲解

上一章我们学会了 **路径参数（Path Parameters）**，现在正式进入第二个重要知识点：**查询参数（Query Parameters）**。

本次讲解以 [FastAPI 官方教程《查询参数》](https://fastapi.tiangolo.com/zh/tutorial/query-params/) 为主线，按照官方章节顺序，结合代码、URL 图解、执行结果和 Agent 开发场景进行讲解。

这一章有 6 个核心知识点：

1. 查询参数是什么，与路径参数有什么区别？
2. 如何设置查询参数的默认值？
3. 如何使用可选参数和 `None`？
4. FastAPI 如何自动转换 `bool` 等数据类型？
5. 如何同时使用路径参数和多个查询参数？
6. 如何设置必填查询参数？

学完后，你将能够理解类似这样的 Agent API：

```text
GET /agents/123?limit=10&include_history=true
```

并知道 FastAPI 是怎么解析每一个参数的。

## 一、什么是查询参数（Query Parameters）？

### 1. 先看一个 URL

假设你开发了一个 Agent 管理系统。

用户需要查询 Agent 列表，并且希望：

- 跳过前 5 个 Agent。
- 最多返回 10 个 Agent。

可以使用这样的 URL：

```text
http://127.0.0.1:8000/agents/?skip=5&limit=10
```

这个 URL 可以拆成三部分：

  
查询参数 URL 结构图

    

/agents/

?

        
skip=5

      
&

        
limit=10

    

    

      
`/agents/`：访问哪个接口

    

      
`?`：查询参数从这里开始

    

      
`skip=5`：参数名为 skip，值为 5

    

      
`&`：用来分隔多个查询参数

    

      
`limit=10`：参数名为 limit，值为 10

  

**记住这三个符号：**

| 符号 | 含义 | 示例 |
|---|---|---|
| `?` | 开始传递查询参数 | `/agents?skip=5` |
| `=` | 给参数赋值 | `skip=5` |
| `&` | 分隔多个参数 | `skip=5&limit=10` |

查询参数在 `?` 后面，以 `参数名=参数值` 的形式出现。

### 2. 和路径参数有什么区别？

这是本章最重要的第一个知识点。

假设有两个 URL：

```text
/agents/123
/agents?limit=10
```

第一个里面的 `123` 是路径参数。

第二个里面的 `limit=10` 是查询参数。

| 对比 | 路径参数 | 查询参数 |
|---|---|---|
| 所在位置 | URL 路径中 | `?` 后面 |
| 使用方式 | `{agent_id}` | `?limit=10` |
| 常见作用 | 确定访问哪个资源 | 筛选、搜索、排序、分页 |
| 是否必须传 | 通常必须 | 可以必填，也可以选填 |
| FastAPI 如何识别 | 参数名出现在路由路径中 | 普通类型参数未出现在路由路径中 |

可以这样理解：

**路径参数：你想找谁？**

```text
/agents/123
```

我要查询编号为 123 的 Agent。

**查询参数：你想怎么查？**

```text
/agents?limit=10
```

我要查询 Agent 列表，但最多只返回 10 个。

这两个概念没有绝对的业务界限，但这种设计符合常见的 REST API 习惯。

### 3. FastAPI 怎么知道哪个是查询参数？

官方教程强调一个重要规则：

> 当函数的普通参数没有出现在路由路径中时，FastAPI 会自动把它识别为查询参数。

例如：

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/agents/")
def get_agents(limit: int = 10):
    return {"limit": limit}
```

观察两处代码：

```python
@app.get("/agents/")
```

和：

```python
def get_agents(limit: int = 10):
```

路由里没有 `{limit}`。

因此，FastAPI 将 `limit` 识别为查询参数。

现在访问：

```text
/agents/?limit=20
```

FastAPI 就会执行类似下面的逻辑：

```python
get_agents(limit=20)
```

返回：

```json
{
  "limit": 20
}
```

**核心规律：参数的位置由 FastAPI 根据路由和参数声明来判断，而不是由 Python 函数名称决定。**

这里先讨论 `int`、`str`、`bool` 等普通标量参数。以后学习请求体和显式的 `Query()` 声明后，你还会看到更丰富的参数定义方法。

## 二、官方第一个例子：`skip` 和 `limit`

这一节我们要理解三个知识点：

- 查询参数如何传入函数。
- 默认值如何工作。
- Python 切片 `[:]` 是什么意思。

### 1. 代码示例

官方使用一个模拟的商品数据库。我们换成你熟悉的 Agent 列表，原理完全相同。

```python
from fastapi import FastAPI

app = FastAPI()

# 模拟数据库
fake_agents_db = [
    {"name": "Chat Agent"},
    {"name": "Code Agent"},
    {"name": "Research Agent"},
    {"name": "Math Agent"}
]

@app.get("/agents/")
def read_agents(skip: int = 0, limit: int = 10):
    return fake_agents_db[skip:skip + limit]
```

这一小段代码已经包含了本章的关键知识。

### 2. `skip: int = 0` 是什么意思？

将它拆成三部分：

```python
skip: int = 0
```

| 部分 | 含义 |
|---|---|
| `skip` | 参数名称 |
| `int` | 声明必须解析为整数 |
| `= 0` | 没有传入时，使用默认值 0 |

也就是说：

**`skip` 表示跳过多少条数据，默认不跳过。**

例如：

```text
/agents/?skip=2
```

会跳过前两个 Agent。

### 3. `limit: int = 10` 是什么意思？

```python
limit: int = 10
```

它表示：

**最多返回多少条数据，默认返回最多 10 条。**

例如：

```text
/agents/?limit=2
```

最多返回前两个 Agent。

### 4. 最难理解的这行：Python 切片

```python
return fake_agents_db[skip:skip + limit]
```

这里的 `[:]` 并不是 FastAPI 专属语法，而是 Python 的列表切片。

先看：

```python
names = ["Chat", "Code", "Research", "Math"]
```

Python 列表中的索引从 `0` 开始：

| 索引 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 值 | Chat | Code | Research | Math |

现在执行：

```python
names[1:3]
```

结果：

```python
["Code", "Research"]
```

为什么不包含 `"Math"`？

因为 Python 切片的规则是：**包含起始位置，不包含结束位置。**

一般形式是：

```python
列表[开始索引:结束索引]
```

因此：

```python
fake_agents_db[skip:skip + limit]
```

等价于：

```text
从第 skip 个索引开始
一直取到 skip + limit 之前
```

例如：

```python
skip = 1
limit = 2
```

实际执行：

```python
fake_agents_db[1:3]
```

返回两个 Agent：

```json
[
  {"name": "Code Agent"},
  {"name": "Research Agent"}
]
```

## 三、默认值：为什么可以不传参数？

这是官方的「默认值」一节。

还是这段代码：

```python
@app.get("/agents/")
def read_agents(skip: int = 0, limit: int = 10):
    return fake_agents_db[skip:skip + limit]
```

关键是两个等号：

```python
skip: int = 0
limit: int = 10
```

这里的 `=` 表示为函数参数设置默认值。

### 1. 不传任何查询参数

访问：

```text
/agents/
```

因为没有提供 `skip` 和 `limit`，所以使用默认值：

```python
skip = 0
limit = 10
```

最终返回全部四个模拟 Agent。

### 2. 只传入一个查询参数

访问：

```text
/agents/?skip=2
```

FastAPI 得到：

```python
skip = 2
limit = 10
```

其中：

- `skip` 使用 URL 中的 `2`。
- `limit` 使用默认值 `10`。

### 3. 两个参数都传入

访问：

```text
/agents/?skip=1&limit=2
```

FastAPI 得到：

```python
skip = 1
limit = 2
```

返回两个 Agent。

| 请求 | skip | limit |
|---|---:|---:|
| `/agents/` | 0 | 10 |
| `/agents/?skip=2` | 2 | 10 |
| `/agents/?limit=1` | 0 | 1 |
| `/agents/?skip=1&limit=2` | 1 | 2 |

所以要记住：

**有默认值的查询参数，调用接口时可以不传；传了就用传入的值。**

### 4. 为什么需要 `int` 类型注解？

假设访问：

```text
/agents/?skip=hello&limit=2
```

由于代码中声明：

```python
skip: int = 0
```

FastAPI 会尝试将 `"hello"` 转换成整数。

转换失败，就会返回 HTTP 422。

再看：

```text
/agents/?skip=1&limit=abc
```

也会返回 422，因为 `limit` 不符合 `int` 类型。

FastAPI 的这些功能与上一章的路径参数是一致的：自动类型解析、数据校验和自动接口文档。

一个额外提醒：FastAPI 能检查是不是整数，但它不知道你的业务规则。例如，负数 `skip=-2` 仍然能够通过普通 `int` 校验。要限制 `skip` 不能小于 0，需要在后面的数值校验章节学习额外约束。

## 四、可选参数：什么是 `str | None = None`？

这是本章最容易让 Python 初学者感到困惑的语法之一。

官方例子中有这样一行：

```python
q: str | None = None
```

我们先弄懂它，再理解 FastAPI 的行为。

### 1. 什么是 `None`？

在 Python 中：

```python
name = "Tom"
age = 18
```

它们都有具体的值。

但有时候，我们希望表示：

> 这个变量目前没有值。

Python 使用 `None` 表示这种情况。

```python
name = None
```

注意：

```python
None    # Python 的空值
"None"  # 一个普通字符串
""      # 空字符串
0       # 数字零
```

它们不是同一个东西。

### 2. 什么是 `str | None`？

```python
q: str | None
```

这是 Python 3.10 及以上版本支持的联合类型写法。

它表示：

**q 可以是字符串，也可以是 None。**

例如：

```python
q = "FastAPI"  # 可以
q = None       # 也可以
```

但是仅仅声明 `str | None`，并不意味着 FastAPI 允许你不传这个参数。

### 3. `= None` 才是这里使参数变成非必填的关键

看完整写法：

```python
q: str | None = None
```

拆开来看：

| 部分 | 含义 |
|---|---|
| `q` | 参数名 |
| `str` | 允许字符串 |
| `\| None` | 也允许 Python 空值 |
| `= None` | 如果没传，就使用 None |

所以：

```python
q: str | None = None
```

实际意思是：

> 用户可以传一个字符串。如果不传，程序就使用 None。

### 4. 结合官方示例理解

我们用 Agent 项目重写一下。

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/agents/{agent_id}")
def get_agent(
    agent_id: str,
    q: str | None = None
):
    if q:
        return {
            "agent_id": agent_id,
            "q": q
        }

    return {"agent_id": agent_id}
```

你已经学过路径参数，所以这次能区分两个参数：

```python
agent_id: str
```

因为路由中存在 `{agent_id}`，它是路径参数。

```python
q: str | None = None
```

因为路由中没有 `{q}`，它是查询参数。

现在测试两个 URL。

**情况 A：不传 q**

```text
/agents/123
```

FastAPI 得到：

```python
agent_id = "123"
q = None
```

程序遇到：

```python
if q:
```

由于 `None` 的布尔值为假，条件不成立。

返回：

```json
{
  "agent_id": "123"
}
```

**情况 B：传入 q**

```text
/agents/123?q=python
```

FastAPI 得到：

```python
agent_id = "123"
q = "python"
```

因为非空字符串在 `if` 判断中为真，所以返回：

```json
{
  "agent_id": "123",
  "q": "python"
}
```

### 5. 一个容易忽略的小细节：`if q` 和 `if q is not None`

假设访问：

```text
/agents/123?q=
```

此时：

```python
q = ""
```

也就是空字符串。

那么：

```python
if q:
```

条件不成立，因为空字符串为假。

但是：

```python
if q is not None:
```

条件成立，因为 `""` 并不等于 `None`。

| q 的值 | `if q` | `if q is not None` |
|---|---|---|
| `"python"` | True | True |
| `""` | False | True |
| `None` | False | False |

这是很实用的 Python 基础知识。

如果你只是想判断用户是否提供了非空的搜索关键词，`if q` 通常就够了。

如果你需要区分“没有传参数”和“传了一个空字符串”，就应该使用 `if q is not None`。

### 6. 必须记住的一个易错点

对比：

```python
q: str | None
```

和：

```python
q: str | None = None
```

这两行**在 FastAPI 中不等价**。

第一行虽然允许 `None` 作为类型，但由于没有提供默认值，在通常的查询参数声明场景下，它仍然是必填参数。

第二行因为有默认值 `None`，所以不是必填参数。

记住：

**是否必填，主要看有没有默认值；允许什么类型，主要看类型注解。**

## 五、查询参数类型转换：`bool` 为什么能接收字符串？

这一节是官方的「查询参数类型转换」。

`bool` 是 Python 的布尔类型，只有两个值：

```python
True
False
```

但 URL 中的查询参数是文本。

例如：

```text
/agents/123?short=true
```

注意，在 URL 里面：

```text
short=true
```

这里的 `true` 是字符串形式的内容，不是 Python 代码里的 `True`。

那么 FastAPI 怎么把它变成布尔值呢？

答案是：**根据你声明的 `bool` 类型，FastAPI 会自动解析和验证。**

### 1. 先看代码

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/agents/{agent_id}")
def get_agent(
    agent_id: str,
    q: str | None = None,
    short: bool = False
):
    agent = {"agent_id": agent_id}

    if q:
        agent.update({"q": q})

    if not short:
        agent.update({
            "description": "This agent helps users solve tasks."
        })

    return agent
```

这段代码和官方示例的逻辑一致。

先不要急着理解全部内容，我们把它拆成四块。

### 2. 第一块：创建一个字典

```python
agent = {"agent_id": agent_id}
```

假设：

```python
agent_id = "123"
```

那么：

```python
agent = {"agent_id": "123"}
```

它只是一个普通 Python 字典。

### 3. 第二块：`dict.update()` 是什么意思？

```python
if q:
    agent.update({"q": q})
```

假设：

```python
q = "FastAPI"
```

那么就执行：

```python
agent.update({"q": "FastAPI"})
```

`update()` 是 Python 字典的方法，作用是向字典添加或更新键值对。

例如：

```python
person = {"name": "Tom"}

person.update({"age": 18})

print(person)
```

结果：

```python
{"name": "Tom", "age": 18}
```

所以在 FastAPI 的代码中：

```python
agent.update({"q": q})
```

就是给返回的数据增加一个 `q` 字段。

也可以用更直观的写法：

```python
agent["q"] = q
```

对于这个例子，效果一样。

### 4. 第三块：`short: bool = False` 是什么意思？

```python
short: bool = False
```

拆解：

- `short`：参数名称。
- `bool`：布尔类型。
- `False`：没有传入时的默认值。

你可以把它理解成一个开关：

  
<!-- 已省略对话中仅用于交互演示的状态代码 -->

    **Agent 详细信息模式**
    
{shortMode?"short=true":"short=false"}

  

      
是否开启简短模式

开启后，省略较长的描述字段

    
开启

  

模拟请求

/agents/123?short={String(shortMode).toLowerCase()}

    
响应 JSON

{JSON.stringify(shortMode?{agent_id:"123"}:{agent_id:"123",description:"This agent helps users solve tasks."},null,2)}

下面我们解释这段判断：

```python
if not short:
```

`not` 是 Python 中的逻辑非运算符。

它会把布尔判断结果反过来。

| short | not short | 是否添加详细描述 |
|---|---|---|
| `False` | `True` | ✅ 添加 |
| `True` | `False` | ❌ 不添加 |

是不是和直觉相反？

其实不是。因为 `short=True` 表示用户想要简短结果，所以程序就不添加详细描述了。

### 5. URL 中的哪些值可以解析为 True？

按照 FastAPI 的布尔值解析规则，下面这些请求都可以让 `short` 变成 `True`：

```text
/agents/123?short=true
/agents/123?short=True
/agents/123?short=1
/agents/123?short=yes
/agents/123?short=on
```

而常见的假值写法包括：

```text
/agents/123?short=false
/agents/123?short=False
/agents/123?short=0
/agents/123?short=no
/agents/123?short=off
```

这些文本会被解析成相应的 Python 布尔值。

但要注意，**不是任何没有被识别为 True 的字符串都会自动变成 False**。

例如：

```text
/agents/123?short=maybe
```

`maybe` 不是受支持的布尔值表示方式，通常会返回 HTTP 422 类型校验错误。

### 6. 把整个执行过程串起来

假设访问：

```text
/agents/123?q=python&short=true
```

FastAPI 得到：

```python
agent_id = "123"
q = "python"
short = True
```

然后执行：

```python
agent = {"agent_id": "123"}
```

因为 `q` 非空：

```python
agent.update({"q": "python"})
```

因为 `short=True`，所以：

```python
if not short:
```

条件不成立，跳过描述字段。

最终返回：

```json
{
  "agent_id": "123",
  "q": "python"
}
```

现在你已经同时用上了路径参数、可选查询参数和布尔查询参数。🎉

## 六、多个路径参数和查询参数可以一起使用吗？

答案是：**完全可以！**

而且这是实际后端开发中非常常见的写法。

假设你有一个接口：

```text
/users/10/agents/123?q=python&short=true
```

其中包含四个参数。

  
同一个 URL 中的四个参数

    

/users/

10

      
/agents/

123

    

      
?

q=python

      
&

short=true

    

  

    
路径参数：user_id、agent_id

  

    
查询参数：q、short

### 1. 代码示例

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/users/{user_id}/agents/{agent_id}")
def get_user_agent(
    user_id: int,
    agent_id: str,
    q: str | None = None,
    short: bool = False
):
    result = {
        "user_id": user_id,
        "agent_id": agent_id
    }

    if q:
        result["q"] = q

    if not short:
        result["description"] = "A personal AI agent."

    return result
```

这四个参数分别来自哪里？

| 参数 | 类型 | 来自哪里 |
|---|---|---|
| `user_id` | int | `/users/{user_id}` |
| `agent_id` | str | `/agents/{agent_id}` |
| `q` | str 或 None | `?q=...` |
| `short` | bool | `&short=...` |

访问：

```text
/users/10/agents/abc?q=FastAPI&short=true
```

FastAPI 会提取：

```python
user_id = 10
agent_id = "abc"
q = "FastAPI"
short = True
```

最后返回：

```json
{
  "user_id": 10,
  "agent_id": "abc",
  "q": "FastAPI"
}
```

### 2. 查询参数的顺序重要吗？

**不重要。**

下面两个 URL 的效果是一样的：

```text
/users/10/agents/abc?q=python&short=true
```

```text
/users/10/agents/abc?short=true&q=python
```

因为查询参数通过名称识别，而不是通过排列位置识别。

也就是说，FastAPI 会找：

```python
q
short
```

它不会认为第一个查询参数一定是 `q`，第二个一定是 `short`。

另外，FastAPI 也不要求函数参数的书写顺序与 URL 中路径参数的顺序一致。它主要根据名称进行绑定。

不过 Python 本身还有一个规则：**没有默认值的普通函数参数必须放在有默认值的参数前面**。所以重排函数参数时，仍需遵守 Python 的语法。

## 七、必选查询参数：为什么有些参数必须传？

前面学了两种写法：

```python
limit: int = 10
```

表示有默认值，可以不传。

```python
q: str | None = None
```

表示没有传入时使用 `None`。

那么，如果我们希望：

**用户必须传入某个查询参数，否则拒绝请求，该怎么写？**

答案很简单：**不要给它设置默认值。**

### 1. 官方示例：`needy` 参数

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/items/{item_id}")
def read_item(item_id: str, needy: str):
    return {
        "item_id": item_id,
        "needy": needy
    }
```

注意：

```python
needy: str
```

这里没有：

```python
= ...
```

所以 FastAPI 将它识别成必选查询参数。

### 2. 不传 needy 会怎样？

访问：

```text
/items/abc
```

FastAPI 发现：

- `item_id` 已经提供。
- `needy` 没有提供。

所以会返回 HTTP 422。

错误信息如下：

```json
{
  "detail": [
    {
      "type": "missing",
      "loc": ["query", "needy"],
      "msg": "Field required",
      "input": null
    }
  ]
}
```

我们逐个解释：

| 字段 | 含义 |
|---|---|
| `type: "missing"` | 缺少必填参数 |
| `loc: ["query", "needy"]` | 缺少的是查询参数 needy |
| `msg: "Field required"` | 这个字段必须提供 |
| `input: null` | 没有收到对应的输入 |

还记得上一章路径参数的 422 吗？

那时你看到：

```json
"loc": ["path", "item_id"]
```

而这次是：

```json
"loc": ["query", "needy"]
```

**`path` 代表路径参数，`query` 代表查询参数。** 这是以后调试接口时特别有用的信息。

### 3. 传入 needy 就能成功

访问：

```text
/items/abc?needy=hello
```

FastAPI 得到：

```python
item_id = "abc"
needy = "hello"
```

返回：

```json
{
  "item_id": "abc",
  "needy": "hello"
}
```

需要注意，`needy: str` 要求参数存在，但并不自动要求它是非空字符串。想禁止 `?needy=` 这种空值，还需要学习下一阶段的字符串校验。

### 4. 三种参数可以混合使用

这也是官方本章的最后一个主要代码示例。

我们用同样的参数组合来理解：

```python
@app.get("/tasks/{task_id}")
def read_task(
    task_id: str,
    needy: str,
    skip: int = 0,
    limit: int | None = None
):
    return {
        "task_id": task_id,
        "needy": needy,
        "skip": skip,
        "limit": limit
    }
```

这里一共有四个参数。

| 参数 | 类型 | 是否必填 | 默认值 |
|---|---|---|---|
| `task_id` | 路径参数 str | 必填 | 无 |
| `needy` | 查询参数 str | 必填 | 无 |
| `skip` | 查询参数 int | 非必填 | 0 |
| `limit` | 查询参数 int 或 None | 非必填 | None |

例如访问：

```text
/tasks/task001?needy=python
```

结果：

```json
{
  "task_id": "task001",
  "needy": "python",
  "skip": 0,
  "limit": null
}
```

注意 JSON 中：

```json
"limit": null
```

因为 Python 的 `None` 在 JSON 中会转换成 `null`。

### 5. 你必须牢记的四种写法

  
查询参数定义对照表

    **① 必填，必须传字符串**
    ```python
    q: str
    ```

  

    **② 非必填，省略时使用默认字符串**
    ```python
    q: str = "hello"
    ```

  

    **③ 非必填，省略时使用 None**
    ```python
    q: str | None = None
    ```

  

    **④ 必填，但类型允许 None**
    ```python
    q: str | None
    ```
    
这里没有设置默认值，所以 FastAPI 仍然要求提供查询参数。类型允许 None，不等于允许省略。

关于第四种写法，你目前只需要知道它和第三种不等价。实际开发中，如果你的目标是“用户可以不传这个参数”，优先使用第三种写法。

### 6. 还有一个知识点：查询参数也可以使用 Enum

官方在章节末尾还提醒，查询参数同样支持上一章学习过的 Enum 枚举。

例如：

```python
from enum import Enum
from fastapi import FastAPI

app = FastAPI()

class AgentMode(str, Enum):
    chat = "chat"
    code = "code"
    research = "research"

@app.get("/agent-mode")
def select_mode(mode: AgentMode = AgentMode.chat):
    return {"mode": mode}
```

访问：

```text
/agent-mode?mode=code
```

结果：

```json
{
  "mode": "code"
}
```

而：

```text
/agent-mode?mode=music
```

会返回 422，因为 `music` 不在合法枚举值中。

到这里，官方《查询参数》这一章的主要内容就已经全部讲完了。

## 十、从 Agent 开发角度，查询参数有什么用？

你学习 FastAPI 的最终目标是开发 Agent，所以还要理解：**这些知识在真实 Agent 项目中有什么实际价值？**

例如，以后你可能需要设计以下 API：

| Agent 功能 | API 示例 | 查询参数用途 |
|---|---|---|
| 查询 Agent 列表 | `GET /agents?limit=10` | 控制返回数量 |
| 搜索 Agent | `GET /agents?search=code` | 搜索关键词 |
| 查询任务记录 | `GET /tasks?skip=20` | 分页查询 |
| 查看 Agent 详情 | `GET /agents/123?verbose=true` | 控制详细程度 |
| 过滤 Agent 类型 | `GET /agents?mode=research` | 筛选 Agent 类型 |

但是，你可能会问：

> 既然查询参数可以传字符串，为什么还需要 POST 请求体？能不能直接把用户向 LLM 提的问题放在查询参数里？

技术上可以传递短文本，但一般**不推荐把长对话内容、敏感信息或 API Key 放在 URL 查询参数中**，因为 URL 容易出现在浏览器历史、服务器日志或其他记录中。

对于 Agent 对话，通常更推荐：

```text
POST /chat
```

然后把用户的问题放在 JSON 请求体中：

```json
{
  "message": "请帮我分析这段 Python 代码",
  "session_id": "abc123"
}
```

需要注意，请求体也不代表自动加密或自动安全，仍然需要 HTTPS、身份验证和适当的数据保护措施。

可以把三种参数这样记忆：

  

      
      **路径参数：定位资源**

    ```text
    GET /agents/123
    ```
    
查询编号为 123 的 Agent。

  

    

      **查询参数：控制查询条件**

    ```text
    GET /agents?limit=10&mode=chat
    ```
    
筛选聊天 Agent，最多返回 10 个。

  

    

      **请求体：提交结构化数据**

    ```text
    POST /chat
    ```
    
把用户问题、会话信息等数据提交给 Agent。

这里的“路径参数、查询参数、请求体”属于参数位置的区别；GET、POST 属于 HTTP 请求方法的区别。它们不是一一绑定的，例如 POST 请求也可以同时包含查询参数和请求体。

## 问题一：FastAPI 如何区分路径参数和查询参数？

**答案：FastAPI 主要通过检查参数名是否出现在 URL 路由的 `{}` 中，来区分路径参数和查询参数。**

- **路径参数（Path Parameters）**：参数名出现在路由路径的 `{}` 中。
- **查询参数（Query Parameters）**：参数名没有出现在路由路径中，并且被声明为 `int`、`str`、`bool` 等普通类型时，FastAPI 通常会将其识别为查询参数。

### 一、代码示例

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/agents/{agent_id}")
def get_agent(agent_id: int, limit: int = 10):
    return {
        "agent_id": agent_id,
        "limit": limit
    }
```

假设访问：

```text
http://127.0.0.1:8000/agents/123?limit=5
```

FastAPI 会这样识别：

| 参数 | 是否出现在路径 `{}` 中 | 参数类型 | 最终值 |
|---|---|---|---|
| `agent_id` | ✅ 是 | 路径参数 | `123` |
| `limit` | ❌ 否 | 查询参数 | `5` |

### 二、FastAPI 的执行过程

  

    **用户发送请求**
    
`/agents/123?limit=5`

  

  

      
      **识别路径参数**

    
发现路由中的 `{`agent_id`}`，提取 `123`，转换成整数。

  

  

      
      **识别查询参数**

    
`limit` 不在路由路径中，从 `?limit=5` 提取并转换成整数。

  

  

    **执行 Python 函数**
    `get_agent(agent_id=123, limit=5)`

最终返回：

```json
{
  "agent_id": 123,
  "limit": 5
}
```

### 三、一个特别容易混淆的地方

FastAPI **不是根据函数参数有没有默认值来区分路径参数和查询参数的**。

例如：

```python
@app.get("/agents/{agent_id}")
def get_agent(agent_id: int, limit: int):
    return {"agent_id": agent_id, "limit": limit}
```

虽然 `limit` 没有默认值，但它仍然是**查询参数**，只不过变成了必填查询参数。

访问 `/agents/123` 会返回 422，因为缺少 `limit`。

而访问 `/agents/123?limit=5` 就能成功。

### 四、一句话总结 ⭐

**路由中有 `{参数名}` → 路径参数；路由中没有 `{参数名}`，且是普通标量参数 → 通常是查询参数。**

至于查询参数是否必填，则取决于有没有提供默认值。

这就是 FastAPI 自动区分路径参数和查询参数的核心机制。
