## Q062｜中｜授课复习

**题目：** 官方最基础的 FastAPI API 测试常使用哪套组合？

- **A.** Jinja2 替代所有单元测试
- **B.** TestClient 发请求、pytest 运行测试、assert 检查结果
- **C.** BackgroundTasks + SSE + File
- **D.** APIRouter 自动评分、Query 自动修复

**正确答案：B. TestClient 发请求、pytest 运行测试、assert 检查结果**

**解析：** `TestClient(app)` 可模拟 HTTP 请求，pytest 发现并执行以 test_ 开头的测试，assert 比较状态码和 JSON 等实际响应与预期。

## Q071｜难｜授课复习

**题目：** Agent 使用真实在线 LLM，回答同一个问题时文字可能略有变化。怎样设计更稳定的 API 自动化测试？

- **A.** 尽量模拟外部模型返回，验证状态码、权限与响应结构，并将生成质量另行评估
- **B.** 强制每次回复与某份几百字文本逐字符一致
- **C.** 跳过所有状态码与权限检查
- **D.** 把 LLM 回复写死成用户密码

**正确答案：A. 尽量模拟外部模型返回，验证状态码、权限与响应结构，并将生成质量另行评估**

**解析：** 真实模型输出具有不确定性。API 的契约、认证和错误处理可以做确定性测试；模型输出质量更适合独立评估，不宜让每次测试都依赖随机长文本完全相同。
