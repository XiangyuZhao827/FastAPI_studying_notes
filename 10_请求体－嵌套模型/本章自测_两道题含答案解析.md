## Q026｜易｜官方补充

**题目：** Agent 的请求模型包含 `config: AgentConfig`，客户端应该怎样提供嵌套配置？

- **A.** 将 config 写成 JSON 子对象，例如 `{"config":{"max_steps":3}}`
- **B.** 只能通过 Cookie 传 config
- **C.** 必须在 URL 路径写完整 Python 类
- **D.** 将 config 放入响应状态码

**正确答案：A. 将 config 写成 JSON 子对象，例如 `{"config":{"max_steps":3}}`**

**解析：** Pydantic 模型可以把另一个 BaseModel 作为字段类型，客户端按 JSON 对象嵌套提交，FastAPI 会逐层解析与验证。这个知识点属于此前未独立讲解的官方补充。

## Q058｜中｜官方补充

**题目：** 某 Agent 接收一组带有 url 和 name 的参考图片信息。如果希望逐项校验，哪种字段注解最合适？

- **A.** `images: list[Image]`，且 Image 是 Pydantic 模型
- **B.** `images: dict`
- **C.** `images: str`
- **D.** `images: int`

**正确答案：A. `images: list[Image]`，且 Image 是 Pydantic 模型**

**解析：** `list[Image]` 表示由多个 Image 子模型构成的列表，每个元素都有字段校验；官方嵌套模型章节还介绍任意深度嵌套和纯列表请求体。
