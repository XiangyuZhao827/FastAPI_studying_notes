## Q009｜易｜授课复习

**题目：** 一个接口声明两个 Pydantic 请求体参数 `item: Item`、`user: User` 时，JSON 通常需要怎样组织？

- **A.** 分别发送两次 HTTP 请求
- **B.** 使用 `item` 和 `user` 两个顶层键
- **C.** 把两个模型写进 URL
- **D.** 只发送 item 中的字段

**正确答案：B. 使用 `item` 和 `user` 两个顶层键**

**解析：** 多个请求体模型参数通常要求 JSON 以参数名为顶层键，例如 `{"item":{...},"user":{...}}`，FastAPI 才能识别两份内容。

## Q055｜中｜授课复习

**题目：** 函数只有一个 `item: Item` 请求体模型参数，又写了 `Body(embed=True)`，JSON 应如何传？

- **A.** `/item/name/book`
- **B.** `?item=book`
- **C.** `{"name":"book"}`
- **D.** `{"item":{"name":"book"}}`

**正确答案：D. `{"item":{"name":"book"}}`**

**解析：** `embed=True` 让单个请求体参数也使用外层参数名作为键。没有 embed 时通常直接提交模型字段组成的 JSON 对象。
