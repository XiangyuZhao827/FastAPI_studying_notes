## Q067｜中｜授课复习

**题目：** `background_tasks.add_task(write_notification, email)` 最直接表示什么？

- **A.** 立即同步执行 write_notification 并在此处等待
- **B.** 把任务可靠存进数据库并自动重试
- **C.** 登记在 HTTP 响应发送完毕之后运行的操作
- **D.** 把响应改成 SSE

**正确答案：C. 登记在 HTTP 响应发送完毕之后运行的操作**

**解析：** BackgroundTasks 允许在响应发送后执行已登记的轻量后续工作；`.add_task()` 只是登记，并不意味着任务此刻完成。

## Q076｜难｜授课复习

**题目：** 一个 LangGraph 深度研究任务需要运行很久，系统重启后也必须恢复、重试。最合理的判断是？

- **A.** 将它写在 GET 路由即可自动可靠
- **B.** 只要关闭 /docs 就能恢复任务
- **C.** BackgroundTasks 天然提供持久化与故障恢复
- **D.** 应考虑独立任务队列、持久化状态与工作进程，而非只依赖 BackgroundTasks

**正确答案：D. 应考虑独立任务队列、持久化状态与工作进程，而非只依赖 BackgroundTasks**

**解析：** BackgroundTasks 适合简单非关键的响应后操作，它依附于当前应用进程，不是可持久化的分布式调度系统。长任务和重试恢复需要专门方案。
