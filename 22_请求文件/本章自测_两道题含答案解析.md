## Q018｜易｜授课复习

**题目：** Agent 需要接收一份可能较大的 PDF 文档，官方教程通常更推荐哪种类型？

- **A.** int
- **B.** bool
- **C.** UploadFile
- **D.** str

**正确答案：C. UploadFile**

**解析：** `UploadFile` 提供文件元信息和文件式读取接口，底层采用可溢写到磁盘的临时文件机制，比一次性用 `bytes` 装入全部内容更适合大文件。

## Q041｜中｜授课复习

**题目：** 调用 `await file.read()` 读取 `UploadFile` 后，再想从头读一次，应该先做什么？

- **A.** `raise HTTPException(404)`
- **B.** `Depends(file)`
- **C.** 重新定义 URL
- **D.** `await file.seek(0)`

**正确答案：D. `await file.seek(0)`**

**解析：** 读取会推进文件指针。`seek(0)` 把读取位置移回开头，随后才能从头再次读取同一份上传文件。
