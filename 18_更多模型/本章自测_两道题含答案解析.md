## Q017｜易｜授课复习

**题目：** 为什么登录接口的输入模型和对外用户信息模型常常分开？

- **A.** 为了让接口只能返回数字
- **B.** 因为 Pydantic 不能复用字段
- **C.** 因为 HTTP 不支持用户名
- **D.** 避免把密码或密码哈希等内部字段对外暴露

**正确答案：D. 避免把密码或密码哈希等内部字段对外暴露**

**解析：** 更多模型章节强调不同用途使用不同模型，输入、数据库内部记录、公开输出可分离，减少敏感信息泄露风险。

## Q091｜难｜授课复习

**题目：** 公开接口要返回 Agent 列表，其中每个内部对象含 `secret_config`。更合理的响应设计是什么？

- **A.** 把 secret_config 改名就安全
- **B.** 通过 Query 参数决定是否隐藏敏感字段且默认公开
- **C.** `response_model=list[AgentPublic]`，只声明允许公开的字段
- **D.** 直接返回全部内部对象并依赖前端隐藏

**正确答案：C. `response_model=list[AgentPublic]`，只声明允许公开的字段**

**解析：** 使用公开版 Pydantic 模型并为列表声明 `list[AgentPublic]`，可以对每项进行响应验证与字段过滤；前端隐藏不等于服务端保密。
