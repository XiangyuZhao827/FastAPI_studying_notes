## Q014｜易｜授课复习

**题目：** 给请求模型配置 `examples` 的主要目的是什么？

- **A.** 直接替客户端发送请求
- **B.** 向 API 文档展示请求示例
- **C.** 绕过 Pydantic 验证
- **D.** 取代所有字段默认值

**正确答案：B. 向 API 文档展示请求示例**

**解析：** 示例帮助前端开发者理解如何填写请求数据，通常显示在 OpenAPI 文档中。示例不等于默认值，也不会绕过校验。

## Q034｜中｜授课复习

**题目：** `Field(examples=["查询天气"])` 与 `Field(default="查询天气")` 的关键区别是什么？

- **A.** 前者会创建路由，后者会删除路由
- **B.** 两者都在没有输入时强制调用 Agent
- **C.** 没有区别
- **D.** 前者用于文档示例，后者影响字段默认值

**正确答案：D. 前者用于文档示例，后者影响字段默认值**

**解析：** `examples` 帮助展示填写样例，不替客户端补数据；`default` 才是在字段缺失时可使用的默认值。
