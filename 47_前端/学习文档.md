# 06｜前端（Frontend）

**FastAPI 用户指南 · 独立复习手册｜核心问题：怎样让用户通过网页使用已开发好的 Agent API？**

官方英文文档：https://fastapi.tiangolo.com/tutorial/frontend/

官方中文入口：https://fastapi.tiangolo.com/zh/tutorial/frontend/

版本提示：`app.frontend()` 是 FastAPI 新版功能（0.138.0 起）。如本地旧版报“没有 frontend 方法”，先查看 `python -m pip show fastapi`，再决定是否升级。

## 一、前端究竟是什么？

以前你通过 `/docs` 里的 Try it out 测试 `POST /chat`。这对开发者很方便，但真实用户希望看到聊天框、发送按钮、历史记录、Agent 头像，以及“正在生成中”的状态。

**前端负责交互和展示，后端负责处理请求和调用 Agent。**

```text
用户在聊天框输入一句话
   → 浏览器 JavaScript 组织 HTTP 请求
   → POST /chat（FastAPI）
   → Agent / LangGraph 执行任务
   → 后端返回 JSON / SSE
   → 浏览器更新聊天页面
```

真实用户并不一定需要手动写 JSON、打开 /docs；HTTP 请求通常由前端代码或 SDK 封装。

## 二、本章的真正重点：提供已经构建好的前端文件

FastAPI 这章不是教 React/Vue 语法，也不会自动生成聊天界面。它讲的是如何把前端框架**构建完成的静态文件**提供给浏览器。

前端项目开发阶段可能有几十个源文件；构建时会运行类似：

```bash
npm run build
```

构建工具随后可能生成：

```text
project/
├── app/
│   ├── __init__.py
│   └── main.py
└── dist/
    ├── index.html
    └── assets/
        └── app.js
```

`dist/` 是前端构建输出，不是 FastAPI 帮你自动生成的内容。`index.html` 是网页入口，`assets` 放 JavaScript、CSS、图片等资源。

## 三、官方核心代码：app.frontend()

```python
from fastapi import FastAPI

app = FastAPI()

app.frontend("/", directory="dist")
```

| 代码 | 作用 | 例子 |
| --- | --- | --- |
| `app.frontend(...)` | 提供已经构建的前端资源 | 可为 React/Vue SPA 提供文件 |
| `"/"` | 前端在什么 URL 前缀提供 | 访问首页 `GET /` |
| `directory="dist"` | 文件在服务器上的目录 | 提供 `dist/index.html` |

例如浏览器请求 `GET /assets/app.js`，FastAPI 可在 `dist/assets/app.js` 找到对应文件。

**重要优先级：**普通路径操作优先于 frontend 文件。你已有的 `POST /chat` 不会因为把前端挂在 `/` 就自动失效；匹配不到普通路由时，才进入前端文件的查找流程。

## 四、什么是 SPA 和客户端路由？

假设你的 Agent 网站有如下页面：

```text
/                      聊天首页
/agents                Agent 列表
/dashboard/settings    设置页面
```

有时服务器磁盘上没有真正的 `dist/dashboard/settings` 文件。前端框架在浏览器里读取当前路径，决定要显示哪个页面。这就是“客户端路由”。

如果用户直接在浏览器地址栏输入 `/dashboard/settings`，服务器若只按真实文件查找，就可能返回 404。为了让前端接管这条导航路径，可以写：

```python
app.frontend("/", directory="dist", fallback="index.html")
```

它的含义是：在适当的浏览器 HTML 导航请求中，找不到匹配的前端文件时，可返回 `index.html`，再由前端路由决定具体页面。

**注意限制：**官方对 fallback 有条件：主要针对接受 HTML 的 `GET`、`HEAD` 导航请求。缺失的 `.js`、`.css`、图片仍会返回 404；未匹配的 `POST` API 不会被一律变成首页。

### fallback 常见取值

| 配置 | 作用 |
| --- | --- |
| `fallback='index.html'` | 浏览器前端导航可回退到入口页面 |
| `fallback='404.html'` | 提供自定义 404 HTML，仍返回 404 状态码 |
| `fallback=None` | 缺失路径直接正常返回 404 |
| `fallback='auto'` | 默认：有 404.html 优先用它，否则有 index.html 则用于合适的导航回退 |

因此不少项目只用 `app.frontend('/', directory='dist')` 即可。

## 五、官方补充功能：目录检查与 Router

`check_dir='auto'` 是默认值。开发环境缺少构建目录时通常只给警告；非开发环境会在创建应用时报告错误，避免把未构建前端的服务部署出去。

- `check_dir=True`：创建应用时始终检查目录。
- `check_dir=False`：跳过创建应用时的检查；如果请求到达时目录还缺失，仍可能报错。

也可以在 Router 上配置前端：

```python
from fastapi import APIRouter, FastAPI

app = FastAPI()
router = APIRouter()
router.frontend("/", directory="dist", fallback="index.html")
app.include_router(router, prefix="/app")
```

这样网页可放在 `/app` 前缀下。主应用和 Router 的相关依赖、中间件也可能作用于前端响应；但 `app.frontend()` **不负责服务端实时渲染（SSR）**。

## 六、Agent 实战：什么时候要用 app.frontend()？

假设你已经开发 `POST /chat`、`GET /agents`，希望用户双击打开网页、选择 Agent、看到文字逐步出现。前端团队用 React/Vue 生成静态构建输出后，可以让 FastAPI 在同一个服务中提供 `dist/`，前端再调用 FastAPI 的 API。

这种方案适用于小型项目、个人演示、部署结构相对简单的应用。如果前端部署在其他域名/CDN，后端只提供 API，那么就不一定需要 `app.frontend()`；跨站调用还可能涉及 CORS 和认证配置。

**职责不要混淆：**

- `app.frontend()`：把文件交给浏览器；
- 前端 JavaScript：组织请求、更新聊天界面；
- `/chat` 路由：接收和验证请求；
- Agent：产生回答或工具执行结果；
- SSE：在需要时把增量内容传给浏览器。

## 七、常见误区

1. **只写 app.frontend 就自动有聊天页面？** 不会，必须先有构建完成的前端文件。
2. **装了 FastAPI 就有 React/Vue？** 不会，前端框架是另一套开发工具。
3. **所有未知 HTTP 请求都会返回 index.html？** 不会，fallback 受到方法与 Accept 等条件限制。
4. **配置在 `/` 会挡住 `/chat`？** 正常路径操作优先，已有 API 可继续工作。
5. **前端与 API 一定必须放同一台服务器？** 不一定，只是一种部署方式。

## 八、5 道复习题（附答案解析）

**1. `dist/` 是由谁生成的？**  答：前端构建流程；FastAPI 负责提供这些已有的静态构建输出。

**2. `app.frontend('/', directory='dist')` 的主要作用？**  答：让浏览器通过相应路径访问已经构建好的前端文件。

**3. SPA 为什么可能需要 fallback='index.html'？**  答：页面路径可能不是磁盘文件，而是由浏览器里的前端路由控制。

**4. 后端写了 POST /chat，同时提供根路径前端，会相互覆盖吗？**  答：正常 FastAPI 路径操作优先，因此不会因前端根路径自动覆盖已定义 API。

**5. 前端能否自动让 Agent 具有推理能力？**  答：不能。前端处理用户体验；Agent 内部业务代码负责推理和工具执行。

## 九、思考题

你准备将一个 Streamlit 原型升级成 React + FastAPI Agent 服务。哪些代码应该放在前端、哪些在 FastAPI、哪些放在 Agent 业务模块中？`app.frontend()` 在哪一层发挥作用？

**参考方向：**React 提供交互；FastAPI 负责路由、验证、安全、响应；Agent 模块运行模型和工具；`app.frontend()` 可用于把 React 已构建的静态资源提供给浏览器。

**本章一句话总结：**前端是用户看到的界面，app.frontend 是提供静态前端构建产物的能力，不是自动生成或运行 Agent。
