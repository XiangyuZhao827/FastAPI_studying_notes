## Q063｜中｜授课复习

**题目：** 下列哪项是密码哈希的正确用途？

- **A.** 只保存 Base64 编码后的明文
- **B.** 从哈希中解密出用户原密码
- **C.** 保存专门密码哈希并验证输入密码是否匹配
- **D.** 把密码放进 JWT 的 Payload

**正确答案：C. 保存专门密码哈希并验证输入密码是否匹配**

**解析：** Argon2 等密码哈希适合存储和验证用户密码，通常不需要也不应“解密”出原始密码。Base64 编码不是密码哈希。

## Q081｜难｜授课复习

**题目：** 对于普通“已签名但未加密”的 JWT，下列哪个说法正确？

- **A.** 只要 JWT 有三段就不需验证签名
- **B.** Payload 可被解码阅读，因此不应放密码或 API Key
- **C.** JWT 永远比服务器端会话更安全
- **D.** Payload 中的密码对客户端不可见

**正确答案：B. Payload 可被解码阅读，因此不应放密码或 API Key**

**解析：** 普通签名 JWT 的 Header 和 Payload 并不保密，签名用于防篡改验证。不能把敏感凭据放入 Payload，也不能只按三段结构判断令牌有效。
