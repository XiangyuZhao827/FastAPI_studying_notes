## Q023｜易｜授课复习

**题目：** 在路由装饰器中声明 `response_model=ChatResponse`，主要目的是？

- **A.** 限制前端输入的 HTTP 方法
- **B.** 定义并检查响应结构、过滤输出字段
- **C.** 自动训练 Chat Agent
- **D.** 生成数据库表

**正确答案：B. 定义并检查响应结构、过滤输出字段**

**解析：** 响应模型作用于对外返回的数据：生成文档、序列化、验证和字段过滤。输入校验通常由请求参数及请求模型承担。

## Q075｜难｜授课复习

**题目：** 用户提交的 JSON 完全合法，但路由返回的数据缺少 `response_model` 要求的必填字段。默认情况下更可能发生什么？

- **A.** 必然返回 204
- **B.** 请求输入验证 422
- **C.** 响应校验失败，服务器端通常返回 500
- **D.** 自动补全任何缺失的用户隐私字段

**正确答案：C. 响应校验失败，服务器端通常返回 500**

**解析：** 输入请求不合法通常是 422；业务端生成了不符合响应模型的数据属于服务器问题，FastAPI 通常抛出响应验证错误并给客户端 500。
