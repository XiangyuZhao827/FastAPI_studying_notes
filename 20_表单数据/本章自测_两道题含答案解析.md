## Q010｜易｜授课复习

**题目：** `Form()` 最直接用于从 HTTP 请求的哪里读取数据？

- **A.** 响应头
- **B.** 表单格式的请求体
- **C.** 服务器配置文件
- **D.** URL 路径

**正确答案：B. 表单格式的请求体**

**解析：** 表单数据位于请求体，常用编码为 `application/x-www-form-urlencoded` 或 `multipart/form-data`；它不同于 JSON 的编码方式。

## Q048｜中｜授课复习

**题目：** 登录接口声明 `username: Annotated[str, Form()]`，客户端却发送 JSON `{"username":"alice"}`，可能出现什么？

- **A.** 必然正常登录
- **B.** 自动变成 OAuth2 JWT
- **C.** FastAPI 自动把它当作 Header
- **D.** 表单字段未被正确提取，导致验证失败

**正确答案：D. 表单字段未被正确提取，导致验证失败**

**解析：** `Form()` 查找表单数据，发送 JSON 属于另一种请求体编码。若必填表单字段缺失，一般得到输入校验错误。
