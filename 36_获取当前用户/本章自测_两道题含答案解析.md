## Q056｜中｜授课复习

**题目：** `get_current_user()` 依赖 `oauth2_scheme` 的典型流程是？

- **A.** 先取得 Bearer Token，再验证并找到对应用户
- **B.** 直接返回上传文件的文件名
- **C.** 把用户写进 URL 路径
- **D.** 先读取 response_model 再获得密码

**正确答案：A. 先取得 Bearer Token，再验证并找到对应用户**

**解析：** 前一层读取令牌字符串，后一层验证令牌并获取用户信息。路由拿到的是已验证用户对象，而不是未经判断的字符串。

## Q087｜难｜授课复习

**题目：** 攻击者已登录为 alice，却在请求 JSON 中自行填写 `"owner":"bob"`。哪个权限判定原则最可靠？

- **A.** 只要 `response_model` 不含 owner 就允许
- **B.** 只检查请求是否为 POST
- **C.** 以用户提交的 owner 为准
- **D.** 以已经验证的用户身份与服务器端资源权限记录为准

**正确答案：D. 以已经验证的用户身份与服务器端资源权限记录为准**

**解析：** 客户端传来的 owner 不能成为授权依据。应使用可信的当前用户依赖，并检查服务器端 Agent 的实际归属或授权关系，防止越权。
