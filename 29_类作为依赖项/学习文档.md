## 2. 类作为依赖项

```python
class CommonQueryParams:
    def __init__(self, q: str | None = None, skip: int = 0, limit: int = 100):
        self.q, self.skip, self.limit = q, skip, limit

@app.get("/items")
def items(commons: Annotated[CommonQueryParams, Depends(CommonQueryParams)]):
    return {"q": commons.q, "skip": commons.skip, "limit": commons.limit}
```

FastAPI 可以检查类构造参数并创建实例。`Depends()` 也可以结合已有的类型注解进行简写；普通 Python 类和 Pydantic BaseModel 不是同一回事。
