# 第二章：Header 参数

## 四、什么是 Header？

HTTP Header 就是请求里的**请求头信息**。

它可以说明客户端或请求的各种属性。

常见请求头包括：

| Header | 典型用途 |
|---|---|
| `Content-Type` | 描述请求体的内容类型 |
| `User-Agent` | 客户端或浏览器标识 |
| `Accept` | 客户端希望接收的响应类型 |
| `Authorization` | 携带身份认证凭据 |
| `X-Request-ID` | 请求追踪标识 |
| `X-Client-Name` | 自定义客户端名称 |

对于 Agent 后端来说，请求追踪标识尤其有价值。

例如，一个 Agent 任务可能经过：

```text
FastAPI → LangGraph → LLM → Search Tool → 数据库
```

如果为请求分配一个追踪 ID，就更容易在不同服务的日志之间关联同一次任务。

不过，客户端自报的 `X-Request-ID` 不能直接作为可信身份凭据；真实系统通常会校验或生成服务端追踪 ID。

## 五、官方代码：读取 User-Agent

官方使用 `user_agent` 参数进行演示。

```python
from typing import Annotated

from fastapi import FastAPI, Header

app = FastAPI()


@app.get("/items/")
async def read_items(
    user_agent: Annotated[str | None, Header()] = None
):
    return {"User-Agent": user_agent}
```

### 1. 它与 Cookie 的代码有什么区别？

对比一下：

```python
ads_id: Annotated[str | None, Cookie()] = None
```

和：

```python
user_agent: Annotated[str | None, Header()] = None
```

它们的 Python 语法几乎一样。

唯一的核心区别是：

- `Cookie()`：去 Cookie 中找数据。
- `Header()`：去普通 HTTP 请求头中找数据。

### 2. 客户端发送什么？

例如：

```http
GET /items/ HTTP/1.1
Host: 127.0.0.1:8000
User-Agent: MyAgentClient/1.0
```

函数中：

```python
user_agent = "MyAgentClient/1.0"
```

结果：

```json
{
  "User-Agent": "MyAgentClient/1.0"
}
```

真实浏览器也通常会自动发送 `User-Agent`，所以你即使没有手动填写，也可能读到一个值。

## 六、重点：为什么 `user_agent` 能读取 `User-Agent`？

这是 Header 章节里最容易考的知识点之一。

你发现没有：

Python 参数是：

```python
user_agent
```

但 HTTP 请求头是：

```http
User-Agent: MyAgentClient/1.0
```

一个使用下划线 `_`，另一个使用连字符 `-`。

**FastAPI 默认会把 Header 参数名中的下划线转换为连字符。**

例如：

| Python 参数名 | 默认对应的 HTTP Header |
|---|---|
| `user_agent` | `user-agent` |
| `x_request_id` | `x-request-id` |
| `x_client_name` | `x-client-name` |
| `if_modified_since` | `if-modified-since` |

另外，**HTTP Header 名称不区分大小写**。

因此：

```http
X-Request-ID: abc123
```

和：

```http
x-request-id: abc123
```

都可以被同一个 `x_request_id` 参数读取。

### 1. 能不能禁止自动转换？

可以：

```python
@app.get("/demo")
def demo(
    strange_header: Annotated[
        str | None,
        Header(convert_underscores=False)
    ] = None
):
    return {"value": strange_header}
```

此时 FastAPI 将按照带下划线的 `strange_header` 查找请求头。

但一般**不建议随意关闭转换**，因为部分代理服务器会拒绝或特殊处理含下划线的请求头名称。

## 七、一个特殊情况：重复的 Header

你之前学过在 Query 中接收列表：

```text
?tag=python&tag=fastapi
```

在 HTTP Header 中也可以重复发送同名字段。

例如：

```http
X-Tag: python
X-Tag: fastapi
```

FastAPI 可以用列表接收：

```python
from typing import Annotated
from fastapi import FastAPI, Header

app = FastAPI()


@app.get("/tags")
def get_tags(
    x_tag: Annotated[list[str] | None, Header()] = None
):
    return {"tags": x_tag}
```

概念上可以得到：

```json
{
  "tags": ["python", "fastapi"]
}
```

具体元素顺序可能受到 HTTP 客户端或底层服务器处理方式影响，因此不要依赖重复 Header 的先后顺序。官方教程也给出了重复 `X-Token` 的示例。

### 🤖 与 Agent 开发的联系

假设你想在内部测试客户端中声明多个标签：

```http
X-Tag: development
X-Tag: agent
```

就可以接收到：

```python
x_tag: list[str]
```

不过，若这些标签属于用户任务本身，像工具列表、知识库选择、检索选项等复杂业务数据，通常更适合放在 JSON Body 中，而不是滥用 Header。
