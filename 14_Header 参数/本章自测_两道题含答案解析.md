## Q070｜中｜授课复习

**题目：** FastAPI 默认如何将 Python 参数名 `user_agent` 与 HTTP Header 对应？

- **A.** 把它放进请求体
- **B.** 只匹配 `user_agent` 且忽略横线
- **C.** 匹配 `User-Agent`
- **D.** 只匹配 Cookie

**正确答案：C. 匹配 `User-Agent`**

**解析：** `Header()` 默认会把下划线转换成连字符，因此 `user_agent` 对应 `User-Agent`，减少 Python 命名与 HTTP Header 名称之间的差异。

## Q073｜难｜授课复习

**题目：** Header 参数 `x_token: Annotated[str, Header(convert_underscores=False)]` 时，调用方应特别注意什么？

- **A.** 该 Header 会被自动加密
- **B.** 此参数将改为 Query
- **C.** Token 自动带有 JWT 签名
- **D.** 下划线不会按默认规则转换为连字符

**正确答案：D. 下划线不会按默认规则转换为连字符**

**解析：** 关闭转换后，FastAPI 不再把参数名中的下划线自动映射成横线。真实代理可能限制含下划线的 Header 名，需要按接口实际约定发送。
