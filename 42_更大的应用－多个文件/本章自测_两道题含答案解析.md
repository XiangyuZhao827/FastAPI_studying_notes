## Q043｜中｜授课复习

**题目：** Agent 平台的 users、agents、chat 接口分布在不同 Python 文件，FastAPI 官方建议用什么组织它们？

- **A.** 一个 APIRouter 负责一组接口，主应用用 include_router 注册
- **B.** 只要有 __init__.py 就会自动向外暴露所有接口
- **C.** 把接口写进 CSS 文件
- **D.** 所有模块必须各自启动 Uvicorn 服务器

**正确答案：A. 一个 APIRouter 负责一组接口，主应用用 include_router 注册**

**解析：** APIRouter 是管理同一应用内路径操作的工具，`app.include_router()` 将路由器加入主 FastAPI 应用，不等于启动多个独立服务。

## Q099｜难｜授课复习

**题目：** 定义 `router = APIRouter(prefix="/agents", tags=["Agents"])`，内部有 `@router.get("/{agent_id}")`，又在主应用注册此 router。哪项正确？

- **A.** 实际路径是 `/agents/{agent_id}`，且统一进入 Agents 文档分组
- **B.** 实际路径是 `/{agent_id}`，前缀自动取消
- **C.** include_router 会自动检查用户权限
- **D.** 所有请求都必须改为 POST

**正确答案：A. 实际路径是 `/agents/{agent_id}`，且统一进入 Agents 文档分组**

**解析：** Router 前缀和内部路径拼接成最终 URL；tags 控制 OpenAPI 分类，并非认证。权限仍需通过 Depends 和业务逻辑实现。
