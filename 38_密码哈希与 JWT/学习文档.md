## 5. 密码哈希与 JWT

- 使用 Argon2 等密码哈希算法存储、验证密码，而不是明文保存。
- JWT 常携带 `sub`、`exp` 等声明；正确验证签名、有效期、必要时还要验证发行者与受众。
- 普通已签名 JWT 的负载不被加密，不能保存密码和 API Key。
- OAuth2 与 JWT 不是同一个概念。教程中的 Password Flow 用于理解底层机制；全新面向第三方或浏览器的标准 OAuth 集成不宜以密码授权流程作为生产默认方案。

## 6. Agent 资源权限

有效令牌表示用户身份已验证，但访问 `agents/{agent_id}` 时仍应检查服务端所有权或授权规则。典型状态码：401 缺少有效凭据，403 身份已确认但无权限，404 资源不存在。

**核心记忆：**登录验证、身份提取、资源授权是不同步骤；`Depends()` 把各步组织在一起。
