## Q031｜中｜授课复习

**题目：** VS Code 中为 FastAPI 路由设置断点，最主要的目的是什么？

- **A.** 让 FastAPI 永远不需要测试
- **B.** 查看程序暂停时实际执行到哪行、变量是什么值
- **C.** 使所有异常自动变成 200
- **D.** 将 Python 程序转换成网页

**正确答案：B. 查看程序暂停时实际执行到哪行、变量是什么值**

**解析：** 调试器可在断点处暂停，帮助观察请求参数、依赖结果和 Agent 返回数据，从而定位错误，而不是自动修复所有问题。

## Q082｜难｜授课复习

**题目：** 调试用的 main.py 写 `if __name__ == "__main__": uvicorn.run(app)`，为什么可以避免测试导入 `app` 时意外启动服务器？

- **A.** 因为 TestClient 会删除 uvicorn
- **B.** 因为 FastAPI 强制要求所有代码在函数外
- **C.** 因为只有直接运行该模块时 `__name__` 才通常是 `"__main__"`，被导入时条件不成立
- **D.** 因为所有 import 都会自动关闭网络

**正确答案：C. 因为只有直接运行该模块时 `__name__` 才通常是 `"__main__"`，被导入时条件不成立**

**解析：** 这段 Python 标准写法区分直接执行与被其他模块导入，便于用调试器运行程序，也避免在测试代码导入 app 时顺手启动独立服务器。
