## Q003｜易｜授课复习

**题目：** 给接口设置 `tags=["Agents"]` 主要影响哪一方面？

- **A.** 数据库事务隔离
- **B.** JSON 的必填字段
- **C.** Token 的签名算法
- **D.** Swagger UI 中的接口分组

**正确答案：D. Swagger UI 中的接口分组**

**解析：** `tags` 是路径操作配置中的文档元数据，方便在 `/docs` 按类别整理接口，不会自动改变接口安全性。

## Q033｜中｜授课复习

**题目：** `@app.post("/agents", status_code=201)` 主要表达什么？

- **A.** 把请求参数改为 201
- **B.** 为成功响应声明状态码 201 Created
- **C.** 把 JWT 有效期设为 201 秒
- **D.** 所有出错请求也返回 201

**正确答案：B. 为成功响应声明状态码 201 Created**

**解析：** `status_code` 配置的是路径操作的默认成功状态码；创建资源时 201 较常见，异常仍可返回 4xx/5xx 等错误状态。
