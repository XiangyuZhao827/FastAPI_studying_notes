## Q068｜中｜授课复习

**题目：** SSE 事件 `event: progress` 和 `data: {"step":"search"}` 中，这两个字段分别表示什么？

- **A.** JWT 签名与用户密码
- **B.** 事件类型与事件携带的数据
- **C.** URL 路径与 Query 参数
- **D.** 文件名与大小

**正确答案：B. 事件类型与事件携带的数据**

**解析：** `event` 用于标识事件类别，`data` 携带实际内容。前端可根据 progress、token、done 等事件类型决定如何更新页面。

## Q089｜难｜授课复习

**题目：** FastAPI 的 `@app.post("/chat/stream", response_class=EventSourceResponse)` 可以返回 SSE。浏览器端最重要的注意事项是什么？

- **A.** 原生 EventSource 通常建立 GET 连接；如需 POST JSON 并接收 SSE，可用 fetch 读取和解析事件流
- **B.** 此时无法发送 Authorization Header
- **C.** SSE 只在 WebSocket 中有效
- **D.** 原生 EventSource 可以任意携带 POST JSON 请求体

**正确答案：A. 原生 EventSource 通常建立 GET 连接；如需 POST JSON 并接收 SSE，可用 fetch 读取和解析事件流**

**解析：** FastAPI 支持以 POST 返回 SSE，但浏览器原生 EventSource 的使用方式以 GET 为主。POST 聊天流通常通过 fetch 和流解析处理，勿混淆服务端格式与客户端 API。
