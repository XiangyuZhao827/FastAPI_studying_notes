## 对话回合 41｜学习内容

`jsonable_encoder()` 是 FastAPI 提供的一个**数据转换函数**。

它的作用是：**把 Python 中的数据转换成可以用 JSON 表示的数据。**

## 一、主要作用

有些 Python 数据不能直接转换为 JSON，例如：

| Python 数据类型 | `jsonable_encoder()` 转换后 |
|---|---|
| Pydantic `BaseModel` | `dict` 字典 |
| `datetime` | ISO 格式的字符串 |
| `set` 集合 | `list` 列表 |
| `UUID` | 字符串 |

例如，Python 的 `datetime` 对象不能直接被标准 JSON 编码器处理，所以需要先转换。

## 二、具体代码示例

假设你的 Agent 返回了回答和执行时间。

```python
from datetime import datetime
from fastapi.encoders import jsonable_encoder
from pydantic import BaseModel


class AgentResponse(BaseModel):
    answer: str
    created_at: datetime


result = AgentResponse(
    answer="你好，我是 Agent",
    created_at=datetime(2026, 10, 28, 12, 30)
)

data = jsonable_encoder(result)

print(data)
```

输出：

```python
{
    "answer": "你好，我是 Agent",
    "created_at": "2026-10-28T12:30:00"
}
```

这里发生了两件事：

1. `AgentResponse` 模型对象转换成了 Python 字典。
2. `datetime` 对象转换成了 JSON 兼容的字符串。

**注意：返回结果仍然是 Python 字典，不是 JSON 字符串。**

## 三、与之前的 model_dump() 的区别

你之前学过：

```python
result.model_dump()
```

它也能把 Pydantic 模型转换为字典。

但默认情况下，字典里的 `datetime` 可能仍然是 Python 的 `datetime` 对象。

而：

```python
jsonable_encoder(result)
```

会进一步把它转换成 JSON 兼容的数据。

另外，Pydantic v2 的 `result.model_dump(mode="json")` 也能完成类似的 JSON 兼容转换。

## 四、什么时候使用？

最常见的是在需要**手动准备 JSON 数据**时，例如保存到 JSON 类型的数据存储，或者自行创建 `JSONResponse`：

```python
from fastapi.responses import JSONResponse

return JSONResponse(
    content=jsonable_encoder(result)
)
```

但如果你只是写普通 FastAPI 接口：

```python
@app.get("/agent", response_model=AgentResponse)
def get_agent():
    return result
```

**一般不需要手动调用 `jsonable_encoder()`。** FastAPI 本身就会处理正常响应的序列化。

---

### 一句话总结

**`jsonable_encoder()` 就是把 Pydantic 模型、datetime 等 Python 数据转换成 JSON 能够表示的普通 Python 数据，方便后续保存或返回。**

记住：它负责**转换数据**，不是直接生成 JSON 字符串，也不是发送 HTTP 响应。
