## Q049｜中｜授课复习

**题目：** Agent 数据中包含 `datetime` 字段，准备把 Pydantic 对象变成可 JSON 序列化的字典时，应优先使用什么？

- **A.** `APIRouter()`
- **B.** `OAuth2PasswordBearer()`
- **C.** `jsonable_encoder()`
- **D.** `Query()`

**正确答案：C. `jsonable_encoder()`**

**解析：** `jsonable_encoder()` 可将日期时间、模型等转换为 JSON 兼容的 Python 结构，但不会替你保存数据库或发送网络请求。

## Q051｜中｜授课复习

**题目：** 需要把包含 `datetime` 的 Pydantic 模型转换为适合 JSON 存储的数据时，更适合使用？

- **A.** `Header()`
- **B.** `Depends()`
- **C.** `print()`
- **D.** `jsonable_encoder()`

**正确答案：D. `jsonable_encoder()`**

**解析：** `jsonable_encoder()` 会递归转换日期时间等常见非原生 JSON 类型，为 JSON 兼容的字典、列表和值；它本身不负责写入数据库。
