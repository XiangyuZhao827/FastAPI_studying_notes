## Q045｜中｜授课复习

**题目：** 某 Agent 接口需要一次接收 PDF 文件和处理指令 `instruction`，官方章节建议的组合是？

- **A.** 两个 JSON Body 和一个文件
- **B.** `Query()` 与 `response_model`
- **C.** 两个独立的 Path 参数
- **D.** `UploadFile` 与 `Form()`

**正确答案：D. `UploadFile` 与 `Form()`**

**解析：** 文件和普通说明字段可以放进同一个 multipart 表单请求：文件由 `File` / `UploadFile` 接收，说明由 `Form()` 接收。

## Q072｜难｜授课复习

**题目：** 设计“上传 PDF + 用户指令 + Agent 处理模式”的 API，哪种请求结构最符合已学内容？

- **A.** 只用响应模型读取上传的文件
- **B.** 将 PDF 原始二进制直接写入 URL 路径
- **C.** 使用 multipart/form-data，文件由 UploadFile 接收，文字字段由 Form 接收
- **D.** 一个请求同时发送两个独立 Content-Type 的请求体

**正确答案：C. 使用 multipart/form-data，文件由 UploadFile 接收，文字字段由 Form 接收**

**解析：** 一个 HTTP 请求体只能按约定格式解析；文件和文本字段一起提交时，multipart 表单是自然方案。后端分别使用文件参数与 Form 字段接收。
