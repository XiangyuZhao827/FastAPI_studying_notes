## Q021｜易｜授课复习

**题目：** `OAuth2PasswordBearer(tokenUrl="token")` 自身会创建 `/token` 登录接口吗？

- **A.** 仅管理员能创建
- **B.** 会自动创建
- **C.** 只有 Docker 环境会
- **D.** 不会，必须另外定义路径操作

**正确答案：D. 不会，必须另外定义路径操作**

**解析：** `tokenUrl` 声明取得令牌的地址并用于 OpenAPI；它不会自动创建登录函数，应用仍需自行实现 `/token`。

## Q096｜难｜授课复习

**题目：** 有人携带 `Authorization: Bearer completely-fake` 请求接口，路由只用了 `Depends(oauth2_scheme)` 并直接返回 token。最大的安全问题是？

- **A.** 只提取了字符串，没有校验真实性
- **B.** Header 中不允许有空格
- **C.** Bearer 只能用于 GET
- **D.** 请求体缺少 JSON

**正确答案：A. 只提取了字符串，没有校验真实性**

**解析：** `OAuth2PasswordBearer` 读取 Bearer 字符串但不验证签名或用户；仅凭它不能证明任何用户已经登录。需要进一步验证令牌和用户状态。
