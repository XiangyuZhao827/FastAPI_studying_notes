## Q040｜中｜授课复习

**题目：** PATCH 的数据更新中，`item.model_dump(exclude_unset=True)` 主要用来保留什么？

- **A.** 响应 Header 的全部信息
- **B.** 客户端实际显式提交的字段
- **C.** 所有字段的默认值
- **D.** 数据库的主键索引

**正确答案：B. 客户端实际显式提交的字段**

**解析：** `exclude_unset=True` 排除未显式设置的字段，以免用模型默认值覆盖已有数据。显式传入的 `null` 与未传入字段不同。

## Q097｜难｜授课复习

**题目：** PATCH 模型字段 `description: str | None = None`，用户显式提交 `{"description":null}`。`model_dump(exclude_unset=True)` 应如何处理？

- **A.** 保留 `description: None`，表达主动清空
- **B.** 把字段自动改成 `False`
- **C.** 完全忽略 description，因为它是 None
- **D.** 强制替换成空字符串

**正确答案：A. 保留 `description: None`，表达主动清空**

**解析：** “未提供字段”和“明确提供 null”不同。`exclude_unset=True` 保留显式提交的 null，允许客户端表达清空 description 的意图。
