## 2. OAuth2PasswordBearer：提取 Bearer Token

```python
from fastapi.security import OAuth2PasswordBearer

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")
```

它从 `Authorization: Bearer <token>` 提取令牌，并在 `/docs` 描述令牌获取地址。它既不自动创建 `/token` 路由，也不自动验证令牌真实性。
