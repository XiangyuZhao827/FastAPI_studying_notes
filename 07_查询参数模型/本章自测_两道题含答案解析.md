## Q020｜易｜授课复习

**题目：** 查询参数模型 `FilterParams(BaseModel)` 的主要用途是？

- **A.** 生成 Agent 的记忆库
- **B.** 读取本地文件
- **C.** 把一组筛选、分页条件组织起来
- **D.** 自动删除过期 Token

**正确答案：C. 把一组筛选、分页条件组织起来**

**解析：** 例如 `limit`、`offset`、`order_by` 放在一个模型中，由 `Query()` 提取和校验，便于维护列表接口。

## Q077｜难｜授课复习

**题目：** Agent 列表查询模型包含 `limit=Field(100, gt=0, le=100)` 与 `order_by: Literal["created_at","updated_at"]`。请求 `?limit=0&order_by=price` 结果最可能是？

- **A.** 自动修改为 limit=100、order_by=created_at
- **B.** 同时存在 limit 越界和非法排序值等校验错误
- **C.** 因为有默认值所以忽略用户输入
- **D.** 正常返回空列表

**正确答案：B. 同时存在 limit 越界和非法排序值等校验错误**

**解析：** 默认值只作用于缺失字段；显式传来的无效值仍要校验。这里 0 不满足 gt=0，price 也不属于 Literal 允许的两个字符串。
