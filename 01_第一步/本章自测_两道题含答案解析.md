## Q004｜易｜授课复习

**题目：** 在最开始的 Agent 练习中，FastAPI 最主要负责什么？

- **A.** 替代 Python 解释器
- **B.** 把 Python 业务函数提供为 HTTP API
- **C.** 自动生成 Agent 的全部思考步骤
- **D.** 训练语言模型

**正确答案：B. 把 Python 业务函数提供为 HTTP API**

**解析：** FastAPI 是 Web API 框架，负责接收网络请求、调用后端逻辑并返回响应。Agent 的推理和工具调用由独立的业务代码或框架完成。

## Q066｜中｜授课复习

**题目：** 你只定义了 `@app.post("/chat")`，直接在浏览器地址栏访问 `/chat`，常见结果是什么？

- **A.** 405 Method Not Allowed
- **B.** 自动打开 `/docs`
- **C.** 必然是 500
- **D.** 正常执行 POST

**正确答案：A. 405 Method Not Allowed**

**解析：** 浏览器地址栏通常发送 GET；若路径存在但不支持 GET，通常返回 405。404 表示没有匹配的路径，422 常表示已匹配后输入校验不通过。
