## Q038｜中｜授课复习

**题目：** 为什么业务中 `raise HTTPException(...)` 比 `return HTTPException(...)` 正确？

- **A.** 因为 HTTPException 专用于打印日志
- **B.** 因为 GET 不支持返回对象
- **C.** 因为 HTTPException 是异常对象，需要抛出
- **D.** 因为 return 只能用于异步函数

**正确答案：C. 因为 HTTPException 是异常对象，需要抛出**

**解析：** 异常处理机制在捕获被抛出的 HTTPException 时生成错误响应；`return` 一个异常实例并不等于通知 FastAPI 按错误状态处理。

## Q061｜中｜授课复习

**题目：** 代码 `raise HTTPException(status_code=404, detail="Agent not found")` 的正确效果是？

- **A.** 只在控制台打印文字
- **B.** 使整个服务器永久停止
- **C.** 终止当前请求正常业务流程并返回 404
- **D.** 正常返回 200 并包含 detail

**正确答案：C. 终止当前请求正常业务流程并返回 404**

**解析：** HTTPException 是异常，要使用 `raise`。找不到 Agent 时它会中断当前请求，交由 FastAPI 错误处理机制生成相应 HTTP 错误响应。
