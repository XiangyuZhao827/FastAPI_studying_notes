## Q032｜中｜授课复习

**题目：** 一个 Agent 服务连续输出下面三行数据：`{"step":"search"}`、`{"step":"analyze"}`、`{"step":"done"}`。这最符合哪种格式？

- **A.** JSON Lines：每行一个独立 JSON 值
- **B.** CSV 表格
- **C.** 一个 WebSocket 握手包
- **D.** 一个完整 JSON 数组的三个成员（必须用方括号包住）

**正确答案：A. JSON Lines：每行一个独立 JSON 值**

**解析：** JSON Lines 允许服务器逐行生成可单独解析的 JSON 数据项；它常用于连续传递结构化记录，通常使用与普通 JSON 不同的响应媒体类型。

## Q085｜难｜授课复习

**题目：** 你用 `yield` 实现 JSON Lines，浏览器却仍然一次性显示所有文字。最可能需要检查哪些方面？

- **A.** 这证明 FastAPI 中的 yield 不会工作
- **B.** 检查数据是否真的分批产生、网络或代理是否缓冲、以及前端是否按流式方式读取
- **C.** 只需将 GET 改成 DELETE
- **D.** 需要关闭所有响应模型

**正确答案：B. 检查数据是否真的分批产生、网络或代理是否缓冲、以及前端是否按流式方式读取**

**解析：** 服务端使用 yield 只负责逐次产出；如果生成器瞬间完成，或中间层/客户端缓冲整段内容，用户就未必看到逐步更新的效果。
