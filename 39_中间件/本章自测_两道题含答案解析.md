## Q047｜中｜官方补充

**题目：** 官方中间件示例中的 `response = await call_next(request)` 主要完成什么？

- **A.** 把请求交给后续处理并取得响应
- **B.** 自动给模型生成 Prompt
- **C.** 清空浏览器 Cookie
- **D.** 立刻创建一个新的数据库

**正确答案：A. 把请求交给后续处理并取得响应**

**解析：** 中间件在路径操作前后运行，`call_next` 将请求传入后续应用处理流程，再返回对应响应，之后中间件还能添加 Header 等信息。

## Q084｜难｜官方补充

**题目：** 官方使用 `X-Process-Time` Header 记录处理耗时。如果 Agent 返回很长的 SSE 流，哪种理解最稳妥？

- **A.** 它表示 JWT 有效期
- **B.** 它只是 Python 安装耗时
- **C.** 这个简单中间件计算的是取得响应对象前后的时间，不能当然视为完整流式传输总耗时
- **D.** 该数字必然精确等于全部 Token 发送完毕的时间

**正确答案：C. 这个简单中间件计算的是取得响应对象前后的时间，不能当然视为完整流式传输总耗时**

**解析：** 官方示例围绕 `await call_next(request)` 计时。在流式响应中，响应对象可能已返回但后续内容仍在产生，不能把这项简单计时无条件理解为整个流的总耗时。
