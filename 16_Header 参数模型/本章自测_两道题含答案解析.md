## Q028｜易｜授课复习

**题目：** Header 参数模型的主要用途是什么？

- **A.** 把响应变成图片
- **B.** 让所有请求绕过认证
- **C.** 把一组相关的请求头声明为模型
- **D.** 自动创建账号

**正确答案：C. 把一组相关的请求头声明为模型**

**解析：** 它帮助集中描述和验证多个 Header，例如客户端标识、追踪 ID 等；验证声明并不等于自动完成安全认证。

## Q037｜中｜授课复习

**题目：** Header 参数模型设置 `extra="forbid"`，核心含义是什么？

- **A.** 让 Header 自动变成 Cookie
- **B.** 让所有请求跳过输入校验
- **C.** 禁用 API 文档
- **D.** 拒绝未在该模型中声明的额外 Header 参数

**正确答案：D. 拒绝未在该模型中声明的额外 Header 参数**

**解析：** `extra="forbid"` 是 Pydantic 模型的额外字段规则；放在 Header 模型中表示严格限制未声明的请求头字段，使用时应考虑客户端自然会发送的各种头。
