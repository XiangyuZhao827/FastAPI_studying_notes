## 装饰器依赖与 APIRouter 依赖

```python
@app.get('/agents', dependencies=[Depends(verify_client)])
def agents():
    return []
```

装饰器依赖会运行检查，但不把返回值直接注入路由参数。

`APIRouter(dependencies=[...])` 影响一组路由。

> 原复习提纲第 4 节将「装饰器依赖、Router 依赖、全局依赖」放在一起，此处按官方章节分开。上方示例中 `verify_client` 需要先由业务代码定义。
