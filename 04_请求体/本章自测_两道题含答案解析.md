## Q024｜易｜授课复习

**题目：** 用户在聊天界面输入一句问题后，前端通常把它作为哪种数据发送给 `POST /chat`？

- **A.** HTTP 状态码
- **B.** Python 源文件
- **C.** 服务器日志
- **D.** JSON 请求体

**正确答案：D. JSON 请求体**

**解析：** 常见 Agent 前端会把输入包装成 JSON，例如 `{"message":"你好"}`，放在 HTTP 请求体中，后端使用 Pydantic 模型解析。

## Q083｜难｜授课复习

**题目：** `POST /agents/7/chat?debug=true` 携带 JSON `{"message":"你好"}`，最合理的数据来源划分是？

- **A.** 7 是 Cookie，debug 是 Header，message 是 Path
- **B.** 三者都是 Body
- **C.** 7 是 Path，debug 是 Query，message 是 Body
- **D.** 7 是 Query，debug 是 Body，message 是 Header

**正确答案：C. 7 是 Path，debug 是 Query，message 是 Body**

**解析：** 路径中的 7 是 Agent 标识，问号后的 debug 是查询参数，请求体中的 message 是 JSON。它们可在同一个 FastAPI 路由函数中同时被解析。
