## Q029｜易｜授课复习

**题目：** 访问 `/agents?skip=5&limit=10` 时，`skip` 和 `limit` 属于哪种参数？

- **A.** Cookie 参数
- **B.** 查询参数
- **C.** 路径参数
- **D.** 文件参数

**正确答案：B. 查询参数**

**解析：** 问号后面的 `skip=5&limit=10` 是 Query 参数，常用于分页、筛选和排序。路径参数则是 URL 路径本身的一部分。

## Q065｜中｜授课复习

**题目：** 查询参数 `short: bool = False`，访问 `?short=true` 通常得到什么？

- **A.** 布尔值 True
- **B.** 整数 1，且不会验证
- **C.** HTTP 404
- **D.** 字符串 `"true"`

**正确答案：A. 布尔值 True**

**解析：** FastAPI 会按 bool 类型注解解析常见布尔文本，如 true/false；传到路径操作函数的通常是 Python 布尔值。
